My Reflection

We learned about advanced CSS techniques this week. I found inheritance interesting because it can be used to better conceuptualizes pieces of websites with lots of moving parts, making css feel more like an OO language. Media queries are super interesting since additional media is essential for making an engaging website, I hope to include all sorts of videos and gifs in my future projects.I also found calculation notation interesting since that would allow me to describe how elements should behave in more situations than what they are predefined for.

My Next Steps

I would like to learn more about media queries and particularly how they can be used to embed live data. This could result in some super fun projects. I think the best way would be to pull up official docs and attempt to integrate it into a project i am already familiar with.
